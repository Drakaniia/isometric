# Interaction patterns

The v2 renderer produces an accessible illustration, not a part-selection runtime. Static SVG has role=img with title and description. Decorative instances use decorative:true. Do not advertise the retired enhance(), layer controls or HTML page shell.

In a framework, keep state in its normal components. The website demonstrates style, theme, facing, pose, weight and size as render options. An open drawing has copy/download actions; every grid tile is a keyboard button. Escape closes the open panel, and / focuses search outside editable fields.

Motion is optional: play on hover/focus, stop on leave/blur, and stop for reduced motion. Touch users must not need hover for essential information. Copied TSX has an animate prop and keyboard focus for hover animation. The model remains editable for deeper interaction.

Use visible focus rings, accessible names, announced copy results and real buttons. Never attach stateful handlers to inner SVG nodes that are replaced every frame. Essential controls belong outside the image.
